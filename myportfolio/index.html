About me

Bridging the gap between software development and production stability.

I approach DevOps not as a collection of tools, but as a culture of reliability, automation, and speed. My core focus is transforming manual, fragile deployment workflows into robust, self-healing cloud ecosystems that empower developers to ship code securely and instantly.

How I Deliver Value:

  • Infrastructure as Code (IaC): I eliminate configuration drift by treating infrastructure exactly like software—versioned, tested, and provisioned via reusable Terraform modules and Ansible playbooks.
  • Container Orchestration: I design, secure, and scale high-availability workloads across AWS EKS (Kubernetes) and ECS, ensuring zero-downtime deployments and dynamic auto-scaling to save on cloud compute overhead.
  • Zero-Touch Automation: I build secure, defensive CI/CD environments (using GitHub Actions and Jenkins) wrapped with automated testing and vulnerability scanning, allowing teams to move fast without introducing vulnerabilities to production.

I thrive in fast-paced environments where engineering velocity meets architecture stability. Let’s collaborate to build systems that scale safely.

Active technical focuses: High-density container scaling, hybrid cloud security patterns, robust telemetry metrics platforms, and cost optimization tracking.
